# edamame default theme.
#
# This file is written on first run from `Theme::default()` and
# `Palette::default()` in src/config/theme.rs — there is no checked-in
# `default.toml` in the source tree.  Every palette entry below is
# commented out: the `# field = value` lines document the compiled-in
# defaults without overriding them at load time, so the live default
# theme tracks the code automatically.  To recolour edamame, uncomment
# any palette line and edit its value (or copy this file to a new
# theme name first — see "Authoring a theme" below).  Lines you leave
# commented fall through to the compiled defaults.  See `theming.md`
# in the repo root for the full design guide.
#
# ─── How theming works ────────────────────────────────────────────────
#
# A theme is a small named palette plus a flat table of styles.  Every
# style in the UI derives from the palette, so re-tinting edamame
# end-to-end is usually a matter of editing the `[palette]` section and
# letting every style fall through.  The palette names map onto roles
# (e.g. "primary", "interactive", "muted"), not specific hues — the
# next section enumerates them.
